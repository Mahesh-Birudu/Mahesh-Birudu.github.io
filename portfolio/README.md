# Portfolio source

Organized source for the public portfolio. index.html is the main page; portfolio-v2.css and portfolio-v2.js manage layout, navigation, carousel and the video dialog; projects.js contains project metadata. m365-profile-cards.html and project-detail.css implement the project detail page. Shared media and download assets remain at the repository root. Root HTML/CSS/JS files are the published GitHub Pages copy. Keep source and deployment copies synchronized when editing.

The portfolio itself is a buildless HTML/CSS/JavaScript website. The Microsoft 365 project in ../projects/m365-profile-cards is the separate React/SPFx/PnPjs solution.
