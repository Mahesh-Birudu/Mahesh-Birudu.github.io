Profiles, photos and presence are loaded through the signed-in SharePoint context. Cards show key contact information; the popup reveals department, office, address and more. Presence includes online availability, meetings, away and offline states.

Configure PnP Search Results

  1. Build and deploy the SPFx package; install or update the site app.
  2. Review Graph User.Read.All, ProfilePhoto.Read.All and Presence.Read.All in SharePoint Admin Center → Advanced → API access.
  3. Upload profile-cards.html to your site's Site Assets library.
  4. Add PnP Search Results, choose SharePoint Search and Local People Results; use {searchTerms} with a connected search box or default * query.
  5. Select AccountName, PreferredName, WorkEmail, JobTitle, WorkPhone, Company, UserName, Path and enable paging.
  6. Enable extensibility library e425e0ca-e11c-45c6-80b2-94c5e6b035ae, keeping the built-in library enabled.
  7. Select the Custom layout and set External template URL to your Site Assets file. Save, test and publish.
